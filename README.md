# Day 2 – Conditions & Loops (Java)

This repository contains Java programs that demonstrate the fundamentals of **conditional statements** and **looping constructs**. These programs are designed for beginners to understand decision-making and iteration in Java.

## 📚 Topics Covered

### Section A – Conditional Statements
- Check whether a number is Positive, Negative, or Zero
- Find the greater of two numbers
- Check whether a number is Even or Odd
- Check whether the sum of two numbers is Even or Odd

### Section B – Looping Constructs
- Print numbers from 1 to 100
- Print alternate odd numbers (1 to 99)
- Print alternate even numbers (0 to 100)
- Print numbers from 100 to 0
- Print numbers from 100 to 1 by skipping two numbers

## ▶️ How to Run


